# SmartCalculator

**Developer:** Vineeth  
A simple calculator built in Java 21 that performs basic arithmetic operations continuously.

## Project Structure

```text
SmartCalculator/
├── docs/
│   └── requirements.md
├── src/
│   ├── main/
│   │   └── java/
│   │       └── com/
│   │           └── savoira/
│   │               └── SmartCalculator.java
│   └── test/
│       └── java/
│           └── com/
│               └── savoira/
│                   └── SmartCalculatorTest.java
├── pom.xml
├── .gitignore
└── README.md
```

## Commands

### Compile Project
```bash
mvn clean compile
```

### Run Tests
```bash
mvn test
```
